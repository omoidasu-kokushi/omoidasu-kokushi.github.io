      1. スプレッドシートを1枚つくる
        Googleスプレッドシートでも Excel でも構いません。1行＝1問、列は左から12列ちょうどに揃えます。
      2. 12列を、この順で埋める

        必須＝空だとその行は取り込まれません／ 推奨＝空でも通りますが機能が死にます／ 任意＝空でも実害なし。
        [？] を押すと、その列が何なのか・どう書くのかが出ます。 8・10・11（問題文／正解／解説）は説明を省いています（読んで分かるため）。 13列目は無くても取り込めます（12列のままで動きます）。

      3. ここがいちばん間違えやすい
        • 10列目は 0 から数えます。1番目の選択肢が正解なら [0] です。[1] と書くと全問ずれます。
        • 8列目は問題文です。解説ではありません。解説は比較表も図解も、すべて11列目に入れます。
        • 11列目の解説は ①②③④ で書き始めてください。この記号を目印に、選択肢ごとの解説へ自動で振り分けます。
        • 解説に「②正解：」のように書いておくと、10列目と食い違う行を自動で見つけて教えます。
        • 図解は ```mermaid 〜 ``` で囲みます。セル内の改行は \n（バックスラッシュ＋n）と書きます。
      4. コピーして貼る
        取り込みたい行をまるごと選択してコピーし、下の欄にそのまま貼り付けて「データを取り込む」。 見出し行が混ざっていても、自動で読み飛ばします。

        取り込み後に「新規◯問／更新◯問／スキップ◯行」が出ます。 スキップされた行は、行番号と理由が出ます。直して貼り直せば、同じ問題は二重に増えず上書きされます。
