## 命名の決まり（2026-09-01 方針）

- **配布ファイル（`sw.js` の `cache.addAll()` 対象）は英語名のまま。**
  日本語名はパーセントエンコードの解釈が環境で割れ、
  **SW登録失敗＝オフライン動作の全損**を実際に招いた（`DESIGN_DECISIONS` §6-2）
- **それ以外（文書・記録・パッチ・新しい道具）は日本語名を既定にする**
- 版付けは `YYYYMMDD_名前_V〇.〇〇`。「完成版」とは名付けない
- コードの識別子（関数名・変数名）は英語のまま。説明は日本語コメントが担う
