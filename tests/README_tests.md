## なぜ file:// で開かないか

`file://` では **IndexedDB も Service Worker も使えない**。
アプリ側の起動自己診断が同じ警告を出すのと同じ理由で、テストも必ず `http://` で走らせる。
`run_all.sh` が `python3 -m http.server` を勝手に立てて、終わったら落とす。

## バッチE で追加した検証（抜粋）

- **取り込みの trim 不具合**（今回の本命）：最終行のタグ列が空でも取り込めること。
  `importText` の `trim()` が区切りタブを食っていたため、V1.14まで**最終行だけが必ず落ちて**いた。
  1列目が空のときは「列数」ではなく「単元が空」と言うこと。前後に空行があっても通ること。
  先頭に空白のあるJSONも復元として認識すること。
- **同梱テンプレート**：`sample/20260816_TSV_Template_V1.00.txt` を**見出し行ごと**貼って、
  2問が取り込まれ、スキップ0であること。見出し行が自動で読み飛ばされること。
- **列ごとの[？]**：9個（1・2・3・4・5・6・7・9・12）あり、**8・10・11には無い**こと。
  col3 に S/A/B/C と重み（×2.5〜×0.3）と「空でOK」があること。
- **Level欄の数字**：`<b class="lv-n">` で包まれ、地の文より**ちょうど1px大きく**太さ800であること。
  `setHtml` 経路でもエスケープが効いていること。
- **使い方カードのタイトル**：番号付き15件はタイトルが空で、大きい太字の行を描画しないこと。
  ラベルとタイトルが重複するカードが0件であること。
- **ポモドーロのON/OFF**：出題中だけトグルが見える／1タップでOFFになり `meta` にも残る／
  OFF中もチップが薄く残る（ONに戻す入口が消えない）／時間は `--:--`（0:00と誤読させない）／
  もう1タップで計測が再開する／**設定のスイッチとヘッダーが同期する**（入口3つで結果1つ）。
  表示は `ON` / `OFF` の文字。`⏸`/`▶` は端末により色付き絵文字に化けるため使わない。


## バッチF で追加した検証（抜粋）

- **一言欄**：34件（33 − 削除3 ＋ 追加4）。削除した3件の本文が1文字も残っていないこと。
  差し替えた3件が**指定文と完全一致**していること（部分一致ではなく全文比較）。
- **評価4ボタンの期間**：カードに書いた期間が、`scheduler.js` の `nextStepIndex()` から
  **実測した値と一致すること**。難＝常に10分／普＝1時間→翌日→1週間で停止／
  易＝初見30日・最短翌日・1日→1週間→30日→90日→180日／マ＝1週間の段では押せず30日の段で180日。
  文言だけ直して実装とズレる事故を防ぐため、毎回突き合わせる。
- **ランダムカードの3段階**：状態判定（初見あり／初見0・未解禁／初見0・解禁済）と、
  **未学習数が取れないときに動線を消さない**こと。
  3状態でカードと主動線の**座標が1pxも動かない**こと。
  読破・いじわるのアイコンが**隣のカード（弱点ノック・力試し）と被らない**こと。
- **全問読破の案内**：到達を認める文があり、いじわる模試の解禁条件が書いてあること。
  解禁後は文面が「このカードから挑戦できます」に変わること。
