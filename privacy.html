プライバシーポリシー

看護師国家試験対策アプリ（以下「本アプリ」）／最終更新：2026年8月21日

本アプリは、個人開発による無料の学習アプリです。 本ポリシーは、本アプリが利用者の情報をどのように扱うかを説明します。

要点
本アプリには、利用者のデータを預かるサーバーがありません。 学習データは利用者の端末内に保存されます。 Googleドライブ同期を使う場合も、保存先は利用者自身のGoogleドライブであり、 開発者が内容を閲覧・取得する手段はありません。

1. 取得する情報と保存場所

情報保存場所開発者による閲覧
解答履歴、選択肢ごとの評価、復習の予定、進捗、設定（試験日・テーマ等） 利用者の端末内（ブラウザのIndexedDB） できません
利用者が取り込んだ問題データ 利用者の端末内 できません

本アプリは、氏名・メールアドレス・住所・電話番号などの個人情報を求めません。 また、アクセス解析ツール、広告配信、トラッキングCookieのいずれも使用していません。

2. Googleドライブ同期について

この機能は任意です。使わなくても、本アプリのすべての学習機能を利用できます。

取得する権限

本アプリは Google の drive.file 権限のみを要求します。 これは「本アプリが作成したファイルのみ」にアクセスできる権限です。 利用者のGoogleドライブにある他のファイル、Gmail、連絡先、カレンダーなどには 一切アクセスできません。

保存されるもの

  • 利用者が問題に貼り付けた画像
  • 利用者が自分の言葉で書き換えた解説文
  • 上記と問題を対応づけるための索引ファイル（notes_index.json）

これらは利用者のGoogleドライブ内の NurseExamApp フォルダに保存され、 利用者自身がいつでも閲覧・削除できます。保存容量は利用者のGoogleアカウントのものを使用します。

開発者が内容を見られない理由

本アプリはブラウザ上のみで動作し、開発者が管理するサーバーを持ちません。 Googleへの認証および通信は利用者の端末から直接行われ、 アクセストークンが開発者の管理する場所を経由することはありません。 したがって、開発者が利用者のファイル内容を取得・保存・閲覧する手段は存在しません。

連携の解除

連携はいつでも解除できます。

  • アプリ内：設定 ＞ ドライブ同期 ＞ ログアウト
  • Google側：Googleアカウントのアクセス権限から本アプリを削除
  • 保存済みのファイルは、利用者自身がGoogleドライブから削除できます

3. 利用者が入力する内容についてのお願い

本アプリでは、利用者が自分で画像やテキストを取り込めます。次の内容は入力しないでください。

  • 著作権のある資料（市販の参考書・問題集の紙面を撮影した画像など）
  • 個人が特定できる情報（患者情報、実習記録、第三者の氏名など）

利用者が入力した内容について、開発者は内容を確認できず、責任を負うことができません。

4. 第三者への提供

本アプリは、利用者の情報を第三者に提供しません。 そもそも開発者は利用者のデータを取得していないため、提供の対象となる情報を保有していません。

Googleドライブ同期を利用する場合、通信の相手方は Google LLC となります。 Google による情報の取り扱いについては Google プライバシーポリシー をご確認ください。

本アプリによる Google API から取得した情報の利用および他アプリへの移転は、 Google API サービスのユーザーデータに関するポリシー （限定的使用要件を含む）に準拠します。

5. データの削除

  • 端末内のデータ：アプリ内の 設定 ＞ リセット・問い合わせ ＞ 全消去。またはブラウザのサイトデータ削除
  • ドライブ上のデータ：利用者自身のGoogleドライブから NurseExamApp フォルダを削除

6. 対象年齢

本アプリは看護師国家試験の受験者を対象としており、13歳未満の方の利用を想定していません。

7. 本ポリシーの変更

内容を変更する場合は、本ページの最終更新日を改めます。 重要な変更がある場合は、アプリ内でお知らせします。

8. お問い合わせ

本ポリシーに関するお問い合わせは、アプリ内の 「設定 ＞ リセット・問い合わせ」に記載の連絡先までお願いします。
