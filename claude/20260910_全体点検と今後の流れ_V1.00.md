## 3. 模試の手応え（M0002〜M0004・9問を精査）

### 属性は完璧です

| 見たところ | 結果 |
|---|---|
| unit / major / medium / rank | 注文と完全一致 |
| pool / variant | 全問 `mock` / `free_a` |
| source | 全問 null（AI予想問題として正しい） |
| sub_item | 全問埋まっている（候補から選択） |
| タグ | マスタ外0件 |
| 中項目の重複 | 0件 |
| statement | 全肢にあり、肢と同じものは0 |
| 出題形式・肢数・正解数 | 注文どおり |

**割り当てをこちらで決めた効果が出ています。** AIが数える余地を残していないので、
過去問レーンで起きた「配分がずれる」「候補外のタグを作る」が1件も起きていません。

中身の質も高いです。実例：

```
在宅酸素療法〈HOT〉を行っている療養者への日常生活指導で適切なのはどれか。
  ○ 火気の近くでは酸素吸入を行わない。
      statement 在宅酸素療法を行っている療養者は、火気の近くで酸素吸入を行わない。
      解説(71字) 高濃度の酸素は燃焼を著しく促進するため、たばこやストーブなどの…
```

### 改善点が2つ。どちらも私のバッチの書き漏れです

**① 肢が長い（21字超が47%）**

```
肢の字数 中央値 20字 ／ 21字超 18/38肢
掃除の規則で一問一答に回るのは 3/9問（33%）
```

指示書には「半分以上を true にできるとなおよい」と書いたのに、
**バッチのヘッダーに「肢は20字以内」を書き忘れました。**
一問一答に回る条件（全肢20字以下）を、作問側が知らない状態で作っています。

**② 全体解説が短い（中央値115字）**

過去問レーンは311字、仕様§4-4は200〜400字。**バッチに字数の目安を書いていません。**
体験用なので短いほうが読みやすいという見方もできますが、
有料版の球と体験版で解説の厚みが違うと、**体験版のほうが薄いという印象**になります。

### 止めるかどうか

**止めません。走り切らせてください。**

- 模試の球としては十分な質です。属性は完璧で、内容も正確
- 一問一答は指示書でも「なおよい」扱いの副次目的。模試を受けてもらうのが主目的
- 途中で差し替えると番号がずれ、PADがどこまで処理したか分からなくなる

**次に球を作るとき（有料版）に、2条件をヘッダーへ足します。**
それだけで一問一答率は33%→7割前後まで上がるはずです。
