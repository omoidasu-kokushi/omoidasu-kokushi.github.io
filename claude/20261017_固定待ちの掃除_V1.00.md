# 固定待ちの掃除 V1.00（2026-10-17）

引き継ぎ V1.53 §5-9 の件。**アプリのコードは触っていない**（版番号・CACHE_NAME は v3.22.0 のまま）。
テストの判定（`ok(...)`）は1つも変えていない。変えたのは待ち方だけ。

## 1. 列挙（直す前）

基準：`__APP_READY` を待つ `wait_for_function` の**次の文**（空行・コメントを飛ばす）が
`wait_for_timeout(N)` か `time.sleep(…)` で、`__INIT_DONE` を待たずに先へ進むもの。

- **103本**（111か所）。うち **覆い等に触れるもの ★ 53本**（61か所）
- ★の判定：コメントを除いたコードに `modal`・`overlay`・`dialog`・`confirm`・`覆い`・`ダイアログ`・`モーダル` のどれかがある
- 引き継ぎ §5-9 の「108本・うち覆い44本」とは数え方が違う（当時の基準は文書に残っていない）。
  今回は `confirm`（`#confirm-go` など確認の覆い）も覆いとして数えたので★が多い
- batchAZ・batchBX はすでに直してあるので入っていない

## 2. 直し方（★53本だけ）

`__APP_READY` の直後の固定待ち1行を、batchBX・batchAZ と同じ形に置き換えた：

```python
    # 固定の待ちをやめ、同梱2本の取り込み完了（__INIT_DONE）を待つ（2026-10-17・引き継ぎ §5-9。もとは pg.wait_for_timeout(1200)）
    _t0 = time.time()
    while time.time() - _t0 < 60:
        if pg.evaluate("() => window.__INIT_DONE === true"):
            break
        pg.wait_for_timeout(200)
    pg.wait_for_timeout(300)
```

- ページの変数（`pg`／`pg2`）と字下げは元の行に合わせた。もとの待ち時間はコメントに残した
- `time` を import していない48本は、先頭の `import` 行に `, time` を足した
- 機械的に置き換えたあと、差分を検査した：消えた行は「固定待ち61行」と「import 行48行」だけ。
  足した行は上の塊だけ。`ok(` を含む行の増減は0
- 引っかかりそうなものは先に読んだ：全初期化→再読込で「見本が戻ってこない」を見るもの（batchBF・seed_resume・free_mock_bundle）は、
  取り込みが終わるまで待つ方が**判定が強くなる**（戻ってくるなら確実に戻ったあとで見る）。
  batchX の2回目（スプラッシュでログインを聞いている間）は `__INIT_DONE` が立たないと60秒止まる心配があったが、実測で止まらなかった
