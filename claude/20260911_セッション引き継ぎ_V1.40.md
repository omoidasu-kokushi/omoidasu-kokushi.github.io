## 8. 作業環境の注意

- フォルダ `国家試験対策室` は **device_request_folder_access で接続できる**（この会話で実測）。device_list_dir／stage／commit_files が使える。device_bash は使っていない
- コンテナから GitHub は **clone は通る・push は 403**。反映は §6
- device_commit_files は**消せない**。消すときはコンピューター操作か利用者の手
- bash は1回120秒まで。長いもの（run_all・通し受験）は `nohup … &` で背景に回してログを見る
- Playwright の起動口：`APP_URL=http://127.0.0.1:8900/index.html`、`window.__APP_READY === true` を待つ
- **`wait_for_function` に async の述語を渡さない。** 値が 0（偽）でも通ることがあった（実測4回中4回）。IndexedDB の数を待つときは Python 側で `evaluate` をループする
- 同梱シードは READY のあと約1秒で249問がそろう。**数を見るテストは249問を待ってから reload する**（§7 の不具合を踏む）
- run_all は単独で。**途中でソースを直したら最初から**（読み込み時点のコードで判定するスイートと、実行時のコードで判定するスイートが混ざる）
- **導出できるものはAIに書かせない**／**数が増えたときこそ、増えた理由を数える**／規則を2か所に持つときは片方だけ直さない（変更なし）
