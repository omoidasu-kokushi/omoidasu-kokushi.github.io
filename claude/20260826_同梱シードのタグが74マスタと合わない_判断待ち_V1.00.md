# 同梱シードのタグが74マスタと合わない — 判断待ち V1.00

2026-08-26 ／ 見つかった版：V1.88 の検証中

---

## 事実（実測）

同梱453問（1,816肢）に付いた概念タグ **1,365個**のうち、
74マスタに当たるのは **21個だけ**。残り1,344個（98.5%）は自由タグで、
**1,145種類**ある（`#マズローの欲求階層説` `#世帯構造` `#反復（繰り返し）` など）。

74テーマのうち、球が1肢でもあるのは **14テーマ**。しかも最大4肢。

```
#看護倫理・法的責任(4) #呼吸・ガス交換生理(3) #医療保険・福祉制度(2)
#在宅療養支援・訪問看護(2) #人口動態統計(1) #保健統計指標(1)
#介護保険・高齢者支援(1) #尿・便・穿刺液検査(1) #感染予防・標準予防策(1)
#急性呼吸不全・人工呼吸(1) #意思決定支援・ACP(1) #誤嚥性肺炎・摂食嚥下訓練(1)
#多職種連携・退院支援(1) #新生児生理・初期評価(1)
```

残る **60テーマは0肢**。

## 何が起きるか

買った直後の利用者（同梱453問しか持っていない）から見ると：

| 機能 | 仕様 | 実際 |
|---|---|---|
| 74概念理解率（§12-2） | 各タグの理解率を出す | 60テーマが `concept_score = null`。14テーマも母数1〜4 |
| 最優先克服概念 TOP 3（§12-3） | 50%未満の下位3つ | 母数が1〜4肢なので、出ても意味が無い |
| 概念別弱点ノック（§7） | 5分＝約20問 | 最大4肢。ホームのサブカード（パルス発光つき）を押しても中身が無い |
| キーワード検索＆概念アナライザー（§12） | ツール一覧の最上段 | 同上 |

**どこにもエラーが出ない。**「押しても問題が来ない」としか見えない。

V1.88 で、**これから取り込むぶん**については取り込みレポートに
「⚠ 74テーマに無いタグ ◯件（◯問）」を出すようにした。
同梱シードは取り込みを経ないので、ここは通らない。

## 選べる案

### 案A：同梱453問に74マスタのタグを付け直す（1,816肢）
- 利点：仕様どおりになる。買った直後から74テーマの機能が動く
- 欠点：1,816肢の再タグ付け。機械ではやれない（1,145種類→74への写像は意味の判断）
- 見積り：作問プロジェクトで、中項目→テーマの対応表を作ってから肢ごとに1つ選ぶ。
  中項目は100種類しか無いので、**中項目→74テーマの対応表を1枚作れば大半は機械で当たる**
  （例：`A. 人口静態・人口動態` → `#人口動態統計`）

### 案B：自由タグを残したまま、74マスタのタグを1つ足す
- 利点：既存の細かいタグ（検索に効いている）を捨てない。追記だけなので安全
- 欠点：肢あたりのタグが増える。理解率の母数の考え方は変わらない
- 仕様§7は「74個から」なので、**仕様の書き方を「74個から必ず1つ。ほかは自由」に直す**必要がある

### 案C：74マスタ自体をやめ、実際に使われているタグから作り直す
- 利点：データに合う
- 欠点：74は商品の売り文句（「74概念アナライザー」）。1,145種類ではアナライザーにならない。**却下でよいと思う**

## 私の推奨

**案B ＋ 中項目→74テーマの対応表**。

理由：
- 自由タグは捨てるには惜しい（`#反復（繰り返し）` のような粒度は検索で効く）
- 中項目は100種類しか無いので、対応表1枚で1,816肢に機械で1つずつ付けられる
- 過去問1,200問（これから作る）にも同じ対応表がそのまま使える。
  **作問プロンプトに対応表を渡せば、以後は最初から74が付く**
- 仕様§7の文言を「74個から必ず1つ。加えて自由タグを付けてよい」に直す

## 決めてほしいこと

1. 案A／案B／案C のどれか
2. 案Bなら、仕様§7の文言をこちらで直してよいか
3. 対応表を作るのは、このプロジェクトか作問プロジェクトか
   （§24では「74概念タグはデータ契約＝このプロジェクト」なので、**対応表もここが正**だと思う）
