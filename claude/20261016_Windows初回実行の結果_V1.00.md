## 3. 直した場所

### 3-1. run_all.sh を直して済んだもの（A の18本すべて）

`tests/run_all.sh` に2つ足した。テスト本体は1本も触っていない。

1. **使う Python を「動くかどうか」で選ぶ**。`python3 -c 'import sys'` が通れば python3、だめなら python（3系であることも確かめる）。
   Windows の `python3` は**存在はする**が Microsoft Store へ飛ばす偽物で、実行すると "Python was not found" で落ちる。
   `which` で判定すると誤る。環境変数 `PYTHON=…` で明示もできる。Linux では従来どおり python3 が選ばれる。
   直したのは `python3 -m http.server` と `python3 "$t"` の2か所
2. **`export PYTHONUTF8=1`**（Python の UTF-8 モード）。標準出力も `subprocess` の `text=True` も UTF-8 になる。
   A の18本はこれだけで通った。Linux では元から UTF-8 なので何も変わらない

### 3-2. テスト本体を編集したもの（1本）

**test_batchX.py**（B）
- 理由：3回目のシナリオで、mock の偽トークンを meta に残したままリロードする。リロード後は mock が外れているので、
  アプリは本物の `https://www.googleapis.com/drive/v3/files?...` へ同期を投げる。
  外へ出られないコンテナでは `ERR_TUNNEL_CONNECTION_FAILED` になり、既存の `_external()` が「外部のエラー」として除外していた。
  この PC では Google まで届いて **401** が返る。その console メッセージ本文には URL が載らない
  （`Failed to load resource: the server responded with a status of 401 ()`）ので除外に引っかからず、NG になった
- 直し：
  - `_external()` に `"googleapis.com"` を足した
  - console の判定に渡す文字列を `m.text` から `m.text + " " + m.location の url` に変えた（行き先で判定できるように）
  - 理由はコメントに書いた
- `pageerror`（捕まらなかった例外）の判定は触っていない

## 4. googleapis.com を除外に足しても、アプリ自身のエラーが握りつぶされていないことの確認

**静的な確認**
- 除外の対象は console の `error` だけ。`pageerror` は今までどおり全部数える
- アプリが自分で出す `console.error` は `'[boot]'`・`'[exam_resume]'` などのタグ＋Error。
  drive.js が作るエラーの文言（「ドライブとの通信に失敗しました（401）」「EXPIRED」など）に **URL は入っていない**
  （`grep "new Error\|throw " drive.js` で全部見た）。発生源の URL はアプリの JS（127.0.0.1）なので、`googleapis.com` に当たらない

**実測**（テスト本体は変えず、スクラッチに写しを作って走らせた）
- console ハンドラを「除外したもの」「数えたもの」に分けて記録し、最終判定の直前にページの中でわざとエラーを5種類起こした
- 結果：
  - **除外されたのは1件だけ**：`401 … https://www.googleapis.com/drive/v3/files?q=…name%3D%27Omoidasu%27…`（上の同期の要求）
  - **わざと起こした5件はすべて数えられた**：
    1. `console.error('[probe] アプリ側の console.error')`
    2. `console.error('[exam_resume]', new Error('ドライブとの通信に失敗しました（401）'))`（「401」「ドライブ」を含むアプリ風の文言）
    3. `setTimeout` の中の throw（捕まらない例外）
    4. 処理されない Promise の reject
    5. 自サーバへの 404（`/no_such_probe_file.png`）
  - その写しでは「実行中にJSエラーが出ていない」が**正しく NG**になった（34/35）
- **残る弱点（承知のうえ）**：アプリ自身が `console.error` の**文字列に** `googleapis.com` を含めて出すと、それも除外される。
  いまそういう出力は無い。既存の `accounts.google.com`・`gsi/client` の除外も同じ性質
