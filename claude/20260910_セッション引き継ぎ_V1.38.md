### §5-③ の答え：variant で選ぶ実装は**要る**（実測）

アプリは `variant` を1か所も見ていない（grep で0件）。模試は V2.80 の単元枠（EXAM_UNIT_SHARE）と
mix（忘れかけ→既習→未見）で組む。必修249問＋体験用90問を入れて、いまの `buildQueue` で組むと：

```
プチ30問  … main 5／free_a 12／free_b 13
```

## 8. 作業環境の注意

- **Linux作業環境（device_bash）はこの会話でも最初からマウント失敗**（「no Plan9 drive shares mounted」）。
  デスクトップのファイルは device_list_dir／device_stage_files／device_commit_files で読み書きできる。
  重い処理はコンテナ側（/root）でやり、結果を commit_files で戻す
- コンテナから GitHub は **clone は通る・push は 403**（§6）
- device_commit_files は**消せない**。消すときはコンピューター操作（エクスプローラーはクリックのみ可）。ターミナルは入力不可、ブラウザは許可不可
- コンピューター操作の許可を1回でも「拒否」すると、**それまでの許可が全部消える**。要求はまとめて1回にする
- bash は1回120秒まで。`python3 -u` で走らせる
- Playwright の起動口：`APP_URL=http://127.0.0.1:8900/index.html`、`window.__APP_READY === true` を待つ
- **導出できるものはAIに書かせない**（確度Cの注記／一問一答の可否／模試の割り当て／字数）
- **数が増えたときこそ、増えた理由を数える**
- 規則を2か所に持つとき（掃除の judge_splittable と storage.js の judgeSplittable と 検証道具の judge_splittable）は**片方だけ直さない**
